# Interface do MVP — direção provisória

Fonte: ../PRD.MVP.md. Público: visitantes de posts de moda no celular e o administrador que cadastra produtos. Não há logo, paleta, fontes ou fotografias de marca aprovados no repositório.

Tese: conectar o código do post ao produto com uma interface editorial enxuta, na qual o código é o elemento de maior destaque.

Decisões provisórias: fundo marfim, texto quase preto, destaque verde escuro; títulos serifados do sistema e controles sans-serif. A home prioriza um único campo; o painel usa lista com miniaturas e ações explícitas. Sem imagens decorativas ou dependências externas. As imagens do painel vêm das URLs reais cadastradas; não há upload nesta entrega.

Verificação: leitura e navegação por teclado, estados vazios/erro/carregamento, layouts mobile e desktop, login por cookie e fluxo CRUD/resolução no navegador. Hospedagem e validação em outro dispositivo ainda dependem do ambiente de produção.
