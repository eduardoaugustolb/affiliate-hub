## Benion

The Instagram automation integration adapts the provider contracts and durable-send design of [Benion](https://github.com/meunomeebero/benion), revision `c291f10213c2972eefd0da287df15ca52e820a33`. The upstream reference fork is [eduardoaugustolb/benion](https://github.com/eduardoaugustolb/benion). Affiliate Hub uses its own TypeScript domain/application ports, PostgreSQL persistence, and HTTP adapters instead of importing the upstream server or file-based state.
